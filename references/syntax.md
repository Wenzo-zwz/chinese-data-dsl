# 中文数据 DSL 语法参考

## 基本约定

- `.zd` 脚本使用 UTF-8 编码。
- 相对路径以 `.zd` 脚本所在目录为基准，不以当前终端目录为基准。
- 表名、数组名和输出变量名必须是合法 Python 标识符，例如 `订单`、`A`、`matrix_a`；不能以数字开头，不能使用 `for`、`class` 等 Python 关键字。
- 一行写一条指令。`#` 后面的内容会作为注释忽略，字符串里的 `#` 不受影响。
- 文件路径和文本值建议用引号包起来，例如 `"订单.csv"`、`"上海"`。

## pandas 指令

```text
读取CSV "订单.csv" 为 订单
读取Excel "订单.xlsx" 为 订单
读取Excel "订单.xlsx" 为 订单 工作表 "Sheet1"
使用 订单

选择 列 ["城市", "品类", "销售额"]
筛选 销售额 大于 1000
筛选 城市 等于 "上海"
筛选 品类 包含 "电脑"

新增列 客单价 = 销售额 / 数量
重命名列 销售额 为 金额
删除空值
删除空值 列 销售额
填充空值 列 销售额 为 0

按 城市 分组 汇总 销售额 求和 为 总销售额
按 ["城市", "品类"] 分组 汇总 销售额 平均 为 平均销售额
按 总销售额 排序 降序

查看前 10 行
保存CSV "结果.csv"
保存Excel "结果.xlsx"
```

比较操作：`大于`、`小于`、`大于等于`、`小于等于`、`等于`、`不等于`、`包含`。

`包含` 按普通文本子串匹配，不按正则表达式匹配。

汇总操作：`求和`、`平均`、`计数`、`最大`、`最小`。

`新增列` 表达式支持列名、数字、引号字符串、括号和 `+ - * /` 运算。例如：

```text
新增列 客单价 = 销售额 / 数量
新增列 含税金额 = 销售额 * 1.13
```

表达式不支持任意 Python 函数调用；需要新增函数时，先扩展 `scripts/zhdata.py` 的受控语法。

## 运行脚本

```powershell
& "<python.exe>" scripts/zhdata.py example.zd
& "<python.exe>" scripts/zhdata.py example.zd --emit-python
& "<python.exe>" scripts/zhdata.py example.zd --output-python generated.py
```

如果目标电脑需要读取或保存 Excel，请确保 Python 环境安装了 `openpyxl`。依赖列表见根目录 `requirements.txt`。
